# Детский сад «Улыбка» — сайт

Next.js 15 (App Router) · TypeScript · Tailwind CSS v4 · Framer Motion · Lucide React. Деплой — Vercel (настройки по умолчанию).

```bash
npm install
npm run dev        # http://localhost:3000
npm run typecheck
npm run build
```

## Устройство

- `src/website/` — композиция для ноутбуков и мониторов (≥ 1024px; проверено на 1024–1920).
- `src/mobile-website/` — отдельная композиция для телефонов (< 1024px; рассчитана на 320–480px).
- `src/shared/` — общее: данные (`data/kindergarten.ts`), переводы RU/KZ (`i18n/`), декоративные фигурки (`ui/Decor.tsx`), галерея, карта, хуки.
- `src/shared/ui/LayoutSwitch.tsx` выбирает версию по ширине экрана через media query (не по user agent).
  Сервер отдаёт обе, CSS сразу показывает нужную, после загрузки лишняя версия удаляется из DOM.

Все факты о детском саде — только в `src/shared/data/kindergarten.ts` и словарях `src/shared/i18n/ru.ts` / `kk.ts`.
Русский — основной язык (его видят поисковики); выбор KZ запоминается в браузере.

## Фотографии и видео

Сейчас в проекте нет фотографий — вместо них показываются аккуратные иллюстрации-заглушки, а в галерее ссылка на Instagram.
Положите файлы в `public/images/` (видео можно и в `public/videos/`) и задеплойте заново — код менять не нужно:

| Файл | Где используется |
| --- | --- |
| `main-page.*` | главный экран (фото или видео) |
| `main-page2.*` | фото → раздел «О нас»; видео → небольшое беззвучное видео на главном экране |
| другие фото | галерея, по имени файла (`image1.jpg`, `image2.jpg`, …); сначала 6 (на телефоне 4), остальные — «Показать ещё» |
| другие видео (`.mp4`, `.webm`, `.mov`) | блок «Видео» под фотографиями; запуск по нажатию, со звуком |

- Если `main-page2` нет, в «О нас» встаёт первое фото галереи.
- Пропорции фото и видео определяются автоматически, в галерее снимки не обрезаются; поворот (EXIF) учитывается, дубликаты показываются один раз.
- Обложка для видео: `<имя>-poster.jpg` рядом с видео.

## Деплой на Vercel

1. Залейте репозиторий на GitHub и импортируйте его в Vercel — настройки по умолчанию (Framework: Next.js).
2. Для своего домена задайте `NEXT_PUBLIC_SITE_URL` (например `https://ulybka.kz`) — от него строятся canonical, sitemap и Open Graph.
   Без переменной используется домен Vercel.
